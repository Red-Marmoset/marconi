# Marconi UI polish

Goal: carry the connection screen's red accent and Nebula typography into the viewer and file browser, with smooth rounded controls and balanced spacing in light and dark themes.

Implementation uses the existing wxWidgets UI. Native buttons retain keyboard, accessibility, default-button and disabled behaviour. Windows painting changes only their appearance; other platforms retain native rendering. File panes receive equal width, compact navigation, scrollable paths, and roomier rows. The existing dockable toolbar receives theme-aware rendering and puts Files among the first actions.
